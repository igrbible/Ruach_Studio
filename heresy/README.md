# HERESY · наши патчи поверх YuE2 Kit v12 (Ruach Studio)

Здесь живут все наши правки Кита. Апстримы не трогаются:

```
../upstream/   yue2.cpp как есть (ServeurpersoCom)
../build/      yue2.cpp + 58 патчей Кита       ← наши engine/1001…
../kit/        репо Кита как есть (IronWolve)   ← наши kit/1001…
```

Номера наших патчей с **1001** — чтобы не столкнуться с патчами Кита,
которые пойдут из апстрима (у него сейчас 0001–0058).

## Как работать

Правка делается коммитом в ветку `heresy` нужного репо, потом:

```bash
./apply.sh --export     # коммиты веток heresy → kit/*.patch, engine/*.patch
./apply.sh --status     # что наложено
```

После обновления Кита (новая версия kit, новый build):

```bash
./apply.sh              # наложит всё, чего нет; уже наложенное пропустит
```

Сравнение идёт по `git patch-id` — хэшу самого изменения, а не по
заголовку: заголовки в `.patch` закодированы в MIME, и кириллица не
сравнивается напрямую.

## Корневые скрипты

`../start.sh`, `../convert-models.sh` и прочие — **копии** из `../kit/app/`,
их кладёт туда установщик Кита. Правится только `kit/app/` (через патч),
корень переписывается `./apply.sh --sync-root`.
