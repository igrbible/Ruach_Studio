Ruach Studio 是在你自己的硬件上运行的开放音乐生成：模型、乐谱、适配器和每一条录音都属于你，没有任何东西按 token 出租。开放模型如今已经足够好，可以独立站稳；缺少的是围绕它们的工作室：这正是我们公开建造的东西。

音乐应当可以自由地创作、自由地分享：没有嗓音、没有乐器、也没有录音室的人，同样有权把自己的思想和感受托付给声音。

七个房间，一个工作室

创作室做出歌曲，写作室与聊天模型一起写它，精修室完成它，画室为它画图，影像室为它策划音乐视频，资料馆收藏每一段录音，LoRA 训练室把你自己的歌教给 YuE2。每个房间的指南都在工作室里。

创作室

风格、歌词、规划模式、解码器、在由绿到红的道路上的 LoRA；录音附带它的乐谱、种子以及重做它所需的一切。

写作室

把歌曲当作带版本的文档，文本配置，以及你自己的聊天模型（或 OpenRouter）与你一起起草和修改。

精修室

频谱、伪影、去嗡声、Whisper 歌词检查、分轨、母带处理、超分；一条链运行全部。

画室

用你自己的提示词为歌曲作画：正方、横幅和竖幅出自同一个种子，由 Qwen-Image 2512 绘制；画面在你眼前显现，正方的那张成为录音的封面。早期预览。

影像室

为录音制作音乐视频：按演唱的歌词行把歌曲切成镜头，场景与写作室一起写，关键帧由画师绘制，动态镜头由 MiniMax H3 生成；可剪辑的时间线、风格（3D LUT、颗粒）、动画样片和成片。测试版。

资料馆

每段录音都在工作区里：可搜索、点赞、备注、锁定、配图、发送到你的 DAW；回收站可以还原。

LoRA 训练室

从你自己的歌曲训练适配器：素材集、训练、两部分的曲线讲解、最值得先听的轮次。

速查表 ♪

200 件乐器，逐一用耳朵试听并评判：YuE2 真正会弹什么，弹得单薄的是什么，不认识的是什么。

指南 · F1

整个 Studio 在 Studio 内部讲清楚，一键即达：每个房间、每个旋钮，它做什么，我们测得的数字，十二种语言。为创作的乐趣而作，而不是为了在网上搜索好几个小时。

是什么让它成为工作室

不是又一个模型外壳：而是围绕模型的工作站，彻底开放，每一处改动都有编号和记录。

  • 完整的歌曲，最长八分钟。一首 6:12 的歌用 135 秒；一首先写乐谱的 7:25 的歌用 212 秒，只用一张 RTX 3090。
  • 先有乐谱，并且由你编辑。YuE2 在一个音响起之前就用 ABC 写出旋律与和弦：修改它们、移调、带来你自己的乐谱或 MIDI，歌曲就跟着它走。
  • 两个种子，而不是一个。保留歌曲（音乐种子），听它重新渲染（声音种子）。
  • 你自己的声音。在工作室里用你自己的歌训练 LoRA，不量化（bf16），遥测会告诉你先听哪些轮次。
  • 后期制作，全部本地。分轨（BS-Roformer、htdemucs）、去嗡声、母带处理、超分（UniverSR）、Whisper 歌词检查。
  • 进入你的 DAW （实验性）。一个 REAPER 工程，含分轨、MIDI 乐谱、时间线上的段落和歌词；为 Waveform 和 Bitwig 提供 DAWproject。
  • 合拍的歌词。每行的拍数对照其段落的标尺：音节按各语言自己的规则计算，自成一拍的辅音也算；输入 «[» 时提示段落标签；找出放错的重音符号。
  • 懂引擎的写手。风格用简短的标签，最重要的放在前面：这是 YuE2 最能遵循的方式。
  • 多张 GPU，多项任务。一张卡合成，其他卡训练；只有一张卡时，页面会告诉你在等什么。
  • 为脚本和智能体准备。在你的机器和网络上提供 API（OpenAPI 3.1）和 MCP 服务器。
  • 你的语言。整个页面及其指南提供英语、俄语、乌克兰语、白俄罗斯语、希腊语、西班牙语、意大利语、法语、葡萄牙语、德语、日语和中文。

防止乱码的守卫

当音乐部分写出损坏的乐谱时（推得太猛的适配器会这样），引擎会在任何音乐建立在它之上之前，几秒内停止运行，并说明原因：哪些适配器、超出极限多少、写出了什么。

强度落在实测的道路上；叠加的适配器共享一个实测的上限。

自己的 LoRA 训练器

工作室在未量化的 bf16 权重上自己训练适配器。在同一素材集上与 Ostris 的 AI-Toolkit 对比，音乐部分的损失每一轮都在 0.015 以内一致。

148 首歌上的秩 16：每步 2.1 秒，12 GB。42 首完整歌曲上的秩 32：每步 6.7 秒，18 GB。

合拍的歌词

每行旁边是它的拍数，对照其段落的标尺：主歌和桥段为一组，预副歌和副歌各自一组。音节按各语言自己的规则计算，自成一拍的辅音也算；段落中的停顿或间奏不会开启新的一组。

在行首输入 «[»，就会像代码编辑器提示单词一样提示段落标签。放错的重音符号会被找出；Ctrl+F 只在该框内查找。

擂台：YuE2 对阵 SUNO v6 与 Musicful

二十张卡片，每张有一行风格描述和一段歌词，原封不动地发给每一方。SUNO v6 和 Musicful V3 按其服务交付的原样；我们的则直接取自引擎、未经处理，于十一月重新演唱，每个峰值都完整保留：原版 YuE2-3B、我们自己的微调 RS-FW 的三个存档点，以及 RS-TW 2.0。这里每个文件都以相同响度播放，谁也不会因为更响而胜出。点一个名字即可收听；同一张卡片上的另一个名字会从同一秒接着播放。

八方都在 RTX 3090 上由 Whisper large-v3 聆听，混音和人声一视同仁：Whisper 的第一行听混音，第二行听分离出的人声，即 BS-Roformer 把每条音轨的所有人声从音乐中分离出来（主唱、和声与合唱一起，从不只取主唱）。没有音乐时，Whisper 有时会漏掉整句歌词，并在停顿处写出没人唱过的字，每一方都会发生，所以两行最好对照着读。

FW 和 TW 是我们对 YuE2 3B 的两个微调的代号：First Wave 和 Tsunami Wave。Tsunami Wave 在 109,250 首曲目、约 6,650 小时上训练：66.7% 的时长是器乐，31.6% 是演唱，1.8% 是说话。人声的语言有英语（时长的 7.0%）、俄语（5.8%）、希伯来语（1.7%）、希腊语和乌克兰语（各 0.6%）、法语和西班牙语（各 0.5%）、葡萄牙语（0.3%）、意大利语（0.2%），以及另外 14 种各占不到 0.1% 的语言；15.9% 的时长里能听到人声，但其语言未能识别。

他们的作品是母带处理过的，我们的是原样，保持解码器自身的电平，每个峰值都完整保留：响度留给母带处理，那是工作室精修室的事。换了种子和提示词，每一方听起来都会不同；擂台展示的是质量和差异范围，而不是最终排名。完整表格及其测量方法：模型卡。

Tsunami Wave 与第一波的词汇

我们两个微调收到的每个词，都已统计并可搜索：Tsunami Wave 的 109,250 首训练曲目，以及在它之前第一波的 32,633 首。流派、乐器、人声、由音频本身得出的情感词、调与 BPM，以及乐谱的字段。很少有微调会公开它的模型被告知了什么。

频谱告诉我们什么

不是听，而是测量的擂台：280 个作品，我们六方各 40 个，SUNO v6 20 个，Musicful V3 20 个。每个作品先统一到 −14 LUFS，让响度赢不到任何东西；每条曲线都是该作品各频段相对其总功率的电平，所以比较的只是形状。我们的是引擎的原始输出，他们的经过母带处理，因此下面的一部分差距来自母带。

用我们自己的代码在 CPU 上测量：1/3 倍频程频段取自 Welch 频谱，响度及其范围依据 ITU-R BS.1770-4 和 EBU Tech 3342。每张图点击即可放大。

立体声告诉我们什么

擂台上的 280 个作品，按宽度来测量。在四个频段中的每一个里，把侧信号（两个声道之差的一半）与中信号（两者之和的一半）相比：侧信号高出中信号的 dB 越多，这个频段听起来就越宽；单声道的作品根本没有侧信号。声像是一个作品里左右声道的电平差摆动得有多远，从第 5 到第 95 百分位，单位 dB。每个数字都是一方作品的中位数：SUNO v6 和 Musicful V3 各 20 个，我们的每一方各 40 个。这里更宽并不更好，只是更宽：这张表不排名次。

接下来

2.0.6 是我们每天创作自己歌曲所用的 Studio。以下是正在路上的较大部分，面向 2.0.7、2.1.0 及以后。

  • 像模型写歌那样编辑歌曲。从任意位置延长一段录音；重写一个段落，保留相邻段落的嗓音、调性和小节，并在模型自己的 token 中缝合；在录音自己的乐谱上叠加一层器乐。
  • DAW，更进一步。录音上方的和弦轨与拍子网格，可从任何录音取参考，以及把你在 MIDI 键盘上弹的写进乐谱的钢琴卷帘。
  • 影像室，更进一步。歌词逐字出现在视频上，所有场景统一色彩。
  • Tsunami Wave 之后的下一波。我们的下一个微调从 YuE2 唱得最差的地方学习，发布前先盲听。
  • 为 REAPER、Waveform 和 Bitwig 提供原生插件，等工作室找到它的用户之后。

ちょっとした話

Ruach Studio の作者 Viktor Zhuromskyy は、話題づくりのためにこれを公開しているのではありません。自分のために作ったのです。有料プランで Suno と半年以上格闘し、取り組むに値するモデルを探し回った末に（ACE-Step、MiniMax ほか）、彼は自分のマシンの上に自分だけのオーディオスタジオを作ろうと決めました。選んだのは YuE2 でした。オープンなモデルの中で、最も割に合い、最も洗練されているからです。

彼は、とりあえず動けばいいという作り方はしませんでした。自分の流儀で作りました。彼の創作は彼自身のもの、洗練された唯一無二のものだからです：自身の翻訳、行間対訳のテキスト、そのほか多くのもの。詰め込めるだけ詰め込み、磨けるだけインターフェースを磨き、スタジオでの創作を、松葉杖と穴ぼこの間を手探りでクリックすることではなく、本当に生産的なものにしました。

話はこれで全部です。これからは、このスタジオはあなたのものでもあります。

一个小故事

Ruach Studio 的作者 Viktor Zhuromskyy 发布它并不是为了炒作。他是为自己做的。在付费套餐上和 Suno 折腾了半年多，又四处寻找值得投入的模型（ACE-Step、MiniMax 等）之后，他决定在自己的机器上搭建一个属于自己的音频工作室。他选定了 YuE2：在所有开放模型中，它最划算，也最精致。

他没有随便拼凑一个能跑就行的工作室，而是按自己的方式来做，因为他的创作也是他自己的，精致而独一无二：他的译本、他的逐行对照文本，还有许多别的。他尽可能多地装进其中，把界面打磨到力所能及的极致，让在这个工作室里的创作不再是在拐杖和坑洼之间胡乱点击，而是真正高效的事。

故事就是这样。现在，这个工作室也是你的了。
